# SAGARIS

> SAGARIS is an agentic revenue operating system for B2B sales teams: CRM, dialer, inbox, SMS, social, an AI receptionist and an AI coach in one system, where AI agents act on the pipeline under approval gates and an audit trail rather than only reporting on it. This file points an agent at the machine-readable surfaces of sagaris.ai and at the pages that answer the common questions.

Pricing is public: 499 USD per founding seat per month for the whole platform, and a custom-priced Enterprise plan on an annual agreement. The pricing page carries schema.org SoftwareApplication and Offer markup for the same figures.

SAGARIS also serves a public REST API and a Model Context Protocol endpoint, both authenticated with a workspace API key. Neither is listed below: they live under /api, which robots.txt disallows, and pointing a crawler at a URL the same site asks it not to fetch is a contradiction rather than a courtesy.
